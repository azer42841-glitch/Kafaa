# منصة سلاسة المعرفية (كفاءة سابقًا)
PHP + MySQL بلا إطار. المجلد العام `public/` هو جذر الموقع، والشيفرة والإعدادات خارجه.
1. أنشئ قاعدة `kafaa` ومستخدمًا لها، ثم شغّل `database/schema.sql`.
2. انسخ `includes/config.local.sample.php` إلى `includes/config.local.php` واملأ بيانات القاعدة.
3. أنشئ مجلد `data/` قابلًا للكتابة من مستخدم الخادم.
4. شغّل محليًا: `php -S 127.0.0.1:8090 -t public` ثم افتح `install.php` لإنشاء حساب المدير.
